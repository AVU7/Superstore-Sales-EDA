# 📊 Superstore Sales Analysis

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on the Superstore dataset to uncover meaningful business insights related to sales, customers, products, shipping, and regional performance.

The main objective of this analysis is to understand:

- Sales trends over time
- Best-performing products and categories
- Customer purchasing behavior
- Regional and city-wise sales performance
- Shipping preferences
- Overall business growth patterns

The project is built using Python and common data analysis libraries in a clean and beginner-friendly manner suitable for showcasing on GitHub.

---

# 🎯 Business Questions

This project attempts to answer questions such as:

- Which product categories generate the highest sales?
- Which regions and states contribute most to revenue?
- What are the monthly sales trends?
- Which products are top-selling?
- Which customer segments generate maximum sales?
- Which shipping mode is most commonly used?

# 🧹 Data Cleaning & Preprocessing

The following preprocessing steps were performed before analysis:

- Checked missing values
- Removed duplicate records
- Converted date columns into datetime format
- Created Month-Year features for trend analysis
- Verified data types
- Cleaned and organized categorical columns

These steps help improve data quality and ensure accurate analysis.

# 📈 Exploratory Data Analysis

## 1. Distribution of Sales

The sales distribution plot shows that most orders have relatively low sales values, while a small number of orders contribute very high sales.

### Insight:

The dataset is right-skewed, indicating the presence of high-value orders.

---

## 2. Monthly Sales Trend

A monthly sales trend analysis was performed to observe sales growth patterns over time.

### Insight:

Sales generally increase over time, with some noticeable fluctuations during specific months.

---

## 3. Top Selling Products

The analysis identified the top 10 products generating the highest revenue.

### Insight:

A few products contribute significantly more revenue than others.

---

## 4. Sales by Category

Sales were compared across different product categories.

### Insight:

Technology category generated the highest sales among all categories.

---

## 5. Sales by Sub-Category

Sub-category analysis helped identify detailed product performance.

### Insight:

Phones and Chairs were among the highest-selling sub-categories.

---

## 6. Regional Analysis

Sales performance was analyzed across:

- Regions
- States
- Cities

### Insight:

The West region contributed the highest overall sales.

---

## 7. Customer Segment Analysis

Customer segments were analyzed to understand purchasing behavior.

### Insight:

The Consumer segment generated the maximum revenue.

---

## 8. Shipping Mode Analysis

Shipping methods were analyzed based on total sales.

### Insight:

Standard Class shipping mode accounted for the highest sales volume.
